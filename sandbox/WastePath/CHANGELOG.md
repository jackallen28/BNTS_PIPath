# 0.4.1 — automatic bin set-up

- **4. Set up bin** now runs by itself, like the Arduino bin's power-up: the lid
  lifts, closes 1° at a time until it presses the button, and asks "Is the lid
  fully shut?" (Yes / Close 5° more / Start again). Then it opens 60° from closed
  (or the saved opening) and asks "Is it open far enough?" (Yes, save it / Open 5°
  more / less). Saving closes the lid onto the button.
- A closed angle a little past the button press ("Close 5° more") is kept: in Live
  the lid closes onto the button, then on to that angle (at most 15° further).
- The set-up stops with a clear message if the button is still pressed after the
  lid lifts, or never presses.

# 0.4.0 — more photos, a calmer servo and bin set-up

- **Servo like the BNTS Arduino bin:** opens at once and stays open at least 2 s;
  closes by sweeping 1° every 15 ms until the closed push button presses, holds
  0.3 s, then goes limp. Without a button it sweeps to the closed angle. Falls back
  to the saved angle (with a ⚠) if the button never presses; warns if it stays
  pressed after opening. Stopping GPIO closes the lid before freeing the pins.
- **4. Set up bin:** a hardware calibration after the photos. It finds the closed
  angle with the button, then opens the lid 5° at a time, tests it and saves both
  angles and the button pin. A live dial shows the servo and the button. The demo
  has a pretend lid.
- **Teach screen:** a box per bin with a progress bar and the last five photos.
  Photos can go past 10 ("+3 extra"); it no longer jumps to Train at 10. The Train
  screen shows a quiz bar per bin with **+ Add more … photos**, and reminds you to
  train again after adding photos.
- GPIO outputs: "Closed button GPIO" field; open/closed angle labels.

# 0.3.1 — ready for a new Raspberry Pi 5

- Find the USB webcam by itself. On a Pi 5, `/dev/video0` can belong to the ribbon
  camera interface, so the first USB picture device is used, and found again if it is
  unplugged and renumbered. A number typed in Setup, or `--camera N`, still works.
- Add `main.py --check`, run at the end of `install.sh`: libraries, the GPIO chip
  through lgpio, and a picture from the webcam. It never moves an output.
- Equal-distance neighbours are ordered the same way on every NumPy (Pi OS Bookworm
  ships NumPy 1.24), and the measurement reference test allows the older OpenCV in
  Pi OS to round a few edge pixels differently.
- The Setup button now says **Photograph empty table**, as the instructions do.
- README: step-by-step setup for a new Pi 5.

# 0.3.0 — restore the original ML Camera workflow

- Restore original full-frame largest-object segmentation, colour/shape scaling,
  weighted neighbour voting, smoothing, photo quiz and novelty threshold.
- Remove the people training category, required item groups and extra geometric /
  motion rejection gates. Require only ten photos of Waste and ten of Recycling.
- Average ten background frames and add the original threshold adjustment.
- Move directly to Live after training. Open the recycling servo on a consistent
  recognised result; flash the LED for waste or unrecognised/uncertain items.
- Stop the LED on an empty table or camera loss. Preserve custom GPIO settings,
  explicit hardware enabling, cleanup and the independent watchdog.
- Back up old-format cropped training and request one new full-frame training set.
- Add regression results generated by running the user's uploaded original program.
